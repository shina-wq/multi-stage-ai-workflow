Run `npm test`.

If any test fails, use `handoffs/spec.md` as the source of truth to decide whether the bug is in `src/` or `tests/`, fix it, and re-run until all tests pass. Do not edit `handoffs/spec.md`.

Then write `handoffs/report.md` with:
1. Final test result (passed / total).
2. Fixes made: file, what changed, and why.
3. Any ambiguities in the spec.
